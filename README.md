## v1.4.0 變更
- 備份：優先走系統分享面板（可存到「檔案」、iCloud、傳給自己），不支援時才下載；今日頁在超過 7 天未備份時提醒，可延後 3 天。
- 儲存：加密資料改存 IndexedDB（寫入排隊、逐次完成），舊版 localStorage 資料首次開啟時自動搬移並驗證後才清除；同時要求瀏覽器「持久儲存」。
- 加密：PBKDF2 迭代數 150,000 → 600,000，記在保險庫內；舊保險庫與舊備份仍可解鎖，解鎖後自動升級。
- 去識別：送給小智前先顯示預覽（可在「我」關閉）；新增地址辨識。名單以外的人名不會自動遮蔽。
- 經文核對 v2：新增安全縮寫（詩、箴、賽、耶、羅、弗、徒、啟、雅、創、申，與林前、帖前、提前、彼前、撒上、王上、代上等），並比對小智緊鄰的「」引文是否與和合本相符。

## v1.5.0 變更
- 全域搜尋（今日頁、羊群頁）：會友、關懷、代禱、講章、會議；標為敏感的關懷內容不會被搜到。
- 匯出行事曆 .ics（我 > 資料）：關懷跟進、服事排程、決議期限、會友生日；可選「含姓名」或「匿名」，不含任何關懷內容。
- 關懷節奏：每位會友可設每週／兩週／每月／兩個月／每季／不提醒，今日頁的問候提醒依此計算。
- 家庭與小組：新增「家庭」欄位；羊群可依小組或家庭分組；會友頁顯示同家庭／小組的人。
- 敏感紀錄：內容預設隱藏、搜尋找不到，可隨時顯示或取消標記；鎖定時自動恢復隱藏。
- 危機偵測 v2：自傷字詞擴充，新增暴力／性侵／虐待提示（113 保護專線）；紀錄或代禱含這些字詞時，自動標為敏感、設明天跟進並跳出提示。專線號碼與字詞請牧者核對。
- 自動化測試：`python3 tests/run_all.py`（需 playwright 與 chromium）。
